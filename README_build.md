## 技术栈

- **后端**: Flask + SQLAlchemy + Flask-Login + Flask-WTF
- **前端**: Bootstrap 5 + jQuery + Jinja2模板
- **数据库**: SQLite（可平滑迁移至PostgreSQL）
- **图表**: Chart.js（用于报表可视化）
- **部署**: 支持本地运行或部署到服务器

## 快速开始

### 1. 安装依赖
```bash
pip install flask flask-sqlalchemy flask-login flask-wtf flask-bootstrap5 werkzeug
```

### 2. 运行应用
```bash
cd myjxc
python run.py
```

### 3. 访问系统
- 访问地址: http://127.0.0.1:5000
- 默认账号: admin / admin123

## 数据库设计

系统包含以下核心表（全部已实现）：
- **users** - 用户表（用户认证和权限管理）
- **products** - 商品表（商品信息和库存管理）
- **categories** - 分类表（商品多级分类）
- **suppliers** - 供应商表（供应商信息和应付余额）
- **customers** - 客户表（客户信息和应收余额）
- **warehouses** - 仓库表（仓库管理）
- **purchase_orders** - 采购订单表（采购订单管理）
- **purchase_order_items** - 采购订单明细表（采购商品明细）
- **stock_ins** - 入库单表（采购入库管理）
- **stock_in_items** - 入库单明细表（入库商品明细）
- **sales_orders** - 销售订单表（销售订单管理）
- **sales_order_items** - 销售订单明细表（销售商品明细）
- **stock_outs** - 出库单表（销售出库管理）
- **stock_out_items** - 出库单明细表（出库商品明细）
- **stock_logs** - 库存流水表（库存变动记录）
- **receipts** - 收款单表（客户收款管理）
- **payments** - 付款单表（供应商付款管理）
- **expenses** - 费用表（日常费用支出管理）
- **logs** - 操作日志表（系统操作记录）

## 使用说明

### 商品管理
1. 登录系统后，点击"基础资料" → "商品管理"
2. 可以添加、编辑、删除商品
3. 支持商品图片上传
4. 支持按分类、关键词搜索商品

### 采购管理
1. 创建采购订单（选择供应商、仓库）
2. 添加商品明细（数量、单价）
3. 确认采购订单
4. 创建入库单（关联采购订单或直接入库）
5. 完成入库后，库存自动更新

### 销售管理
1. 创建销售订单（选择客户、仓库）
2. 添加商品明细（数量、单价）
3. 确认销售订单
4. 创建出库单（关联销售订单或直接出库）
5. 完成出库后，库存自动扣减

### 库存管理
1. 点击"库存管理" → "库存概览"查看整体库存情况
2. 查看低库存预警商品列表
3. 进行库存盘点操作
4. 执行仓库间库存调拨
5. 查看库存流水记录了解库存变动历史

### 财务管理
1. 点击"财务管理" → "财务概览"查看财务统计数据
2. 管理客户收款记录
3. 管理供应商付款记录
4. 记录日常费用支出
5. 查看利润分析报告

### 报表分析
1. 点击"报表分析" → "报表首页"查看销售趋势图表
2. 生成进销存报表分析商品流转
3. 查看销售排行榜了解畅销商品
4. 分析客户消费行为和供应商采购情况
5. 查看经营日报了解每日经营状况

### 系统功能
1. 点击"系统功能" → "系统首页"查看系统信息
2. 查看操作日志记录
3. 进行数据备份和恢复操作
4. 管理员可以管理用户账户和权限
5. 配置系统参数设置
