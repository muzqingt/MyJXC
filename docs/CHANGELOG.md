# Changelog

## [1.0.0] - 2026-06-03

### Added
- 采购管理模块（订单、入库、退货）
- 销售管理模块（订单、出库、退货）
- 库存管理模块（盘点、调拨、调整、日志）
- 财务管理模块（收款、付款、费用、利润分析）
- 报表分析模块（进销存报表、销售排行、客户/供应商统计）
- 系统管理模块（用户、设置、备份、日志）
- pytest 测试基础设施（fixtures、工厂函数）
- 188 个自动化测试用例
- 核心业务逻辑 ~85% 测试覆盖率

### Fixed
- `generate_order_number()` 处理 PurchaseReturn 时的属性访问错误
- 测试数据库隔离问题（DATABASE_URL 环境变量）

### Changed
- 核心模型方法添加类型提示
- 统一错误处理模式（SQLAlchemyError）
