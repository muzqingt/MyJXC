# REQUIREMENTS: v2.0.0 AI 单据识别

## 1. 系统配置

### R1.1 AI API 配置
- 系统设置页添加"AI 配置"区域
- 配置项：API 地址、API 密钥、模型名称
- 存储在 SystemSetting 表
- 密钥字段脱敏显示（只显示前 4 位 + ****）
- 未配置时所有识别按钮不显示

### R1.2 配置验证
- 提供"测试连接"按钮
- 调用 API 验证密钥有效性
- 显示连接结果（成功/失败 + 错误信息）

## 2. AI 识别引擎

### R2.1 后端 API
- `POST /api/ai/recognize` 接口
- 接收：图片 base64、单据类型（order/stock/receipt/payment/expense/return）
- 调用 OpenAI 兼容 API，发送图片 + prompt
- 返回结构化 JSON 数据

### R2.2 Prompt 设计
- 根据单据类型使用不同 prompt
- 要求返回固定格式 JSON
- 包含字段映射说明
- 示例：采购订单返回 `{supplier_name, items: [{name, quantity, price}], ...}`

### R2.3 错误处理
- API 超时（10 秒）提示用户重试
- API 密钥无效提示检查配置
- 识别结果为空提示重新拍照
- 网络错误友好提示

## 3. 前端拍照组件

### R3.1 拍照按钮
- 所有单据创建页添加"拍照识别"按钮
- 按钮样式：蓝色虚线边框，相机图标
- 支持两种输入：拍照（移动端）和选择文件（桌面端）

### R3.2 图片处理
- 支持 JPG/PNG 格式
- 自动压缩到 1MB 以内（Canvas 压缩）
- 显示预览图
- 识别中显示加载动画

### R3.3 识别结果确认
- 识别完成后弹出确认对话框
- 显示识别结果摘要
- 用户确认后自动填写表单
- 用户可取消重新拍照

## 4. 表单自动填写

### R4.1 采购订单
- 供应商名称匹配（模糊匹配已有供应商）
- 商品明细自动填充（名称/编码匹配已有商品）
- 数量、单价自动填写
- 备注字段

### R4.2 销售订单
- 客户名称匹配
- 商品明细自动填充
- 数量、单价自动填写

### R4.3 入库单/出库单
- 关联订单号
- 商品明细
- 数量

### R4.4 收款单/付款单/费用单
- 金额
- 日期
- 支付方式
- 备注

### R4.5 退货单
- 关联订单号
- 退货商品明细
- 退货数量

## 5. 可插拔设计

### R5.1 功能开关
- 未配置 API 时，拍照按钮不显示
- 配置错误时，点击按钮提示"请先配置 AI 服务"
- 不影响原有表单功能

### R5.2 多模型支持
- 兼容 OpenAI、DeepSeek、通义千问等 OpenAI 兼容 API
- 通过配置切换模型
- 默认 prompt 适配中文场景
