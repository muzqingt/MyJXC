# PROJECT: my-jxc 进销存管理系统

## 项目概述
基于 Flask 的中小企业进销存管理系统，覆盖采购、销售、库存、财务、报表五大业务模块。

## 里程碑历史

### v1.0.0 (2026-06-03) — 基础功能
- 采购/销售/库存/财务/报表五大模块
- 188 个自动化测试
- 核心业务 ~85% 测试覆盖率

### v1.1.0 (2026-06-08) — 质量修复
- 清理死代码（~724 行）
- 修复错误处理（自定义错误页面、异常信息保护）
- 中文化（模板、导出、错误消息）
- 生产服务器支持（waitress）

### v2.0.0 (当前) — 功能增强
**目标：** 批量操作 + 消息提醒 + 数据看板

#### 核心需求
1. **批量操作** — 批量删除、批量审核、批量导入导出
2. **消息提醒** — 库存预警通知、订单到期提醒、应收应付提醒
3. **数据看板** — 销售/采购/库存趋势图表、同比环比分析

#### 技术约束
- SQLite 单写限制（批量操作需考虑锁策略）
- 现有 Bootstrap 5 + jQuery 前端架构
- 无 WebSocket（提醒需轮询或页面刷新）
