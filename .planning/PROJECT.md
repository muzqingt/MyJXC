# PROJECT: my-jxc 进销存管理系统

## 项目概述
基于 Flask 的中小企业进销存管理系统，覆盖采购、销售、库存、财务、报表五大业务模块。

## 里程碑历史

### v1.0.0 (2026-06-03) — 基础功能
- 采购/销售/库存/财务/报表五大模块
- 188 个自动化测试
- 核心业务 ~85% 测试覆盖率

### v1.1.0 (2026-06-08) — 质量修复
- 清理死代码（~724 行）
- 修复错误处理（自定义错误页面、异常信息保护）
- 中文化（模板、导出、错误消息）
- 生产服务器支持（waitress）

### v2.0.0 (当前) — AI 单据识别
**目标：** 拍照识别单据并自动填写表单

#### 核心需求
1. **AI 识别引擎** — 调用 OpenAI 兼容 API，传入图片返回结构化数据
2. **拍照/上传组件** — 所有单据创建页添加拍照识别按钮
3. **表单自动填写** — 识别结果映射到表单字段
4. **系统配置** — 数据库配置 API 地址、密钥、模型名称

#### 适用页面
- 采购订单、销售订单
- 入库单、出库单
- 收款单、付款单、费用单
- 采购退货、销售退货

#### 技术方案
- OpenAI 兼容 API（支持 OpenAI / DeepSeek / 通义千问等）
- API 配置存储在 SystemSetting（数据库）
- 前端通过 FileReader + Canvas 获取图片 base64
- 后端代理调用 AI API（避免前端暴露密钥）
- 可插拔：未配置 API 时按钮不显示
